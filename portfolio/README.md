# Portfolio (Next.js)

Pages: Home (`/`), About (`/about`), Projects (`/projects`).

## Run it
1. Install Node.js 18.18 or newer.
2. Open this folder in VS Code, then open the terminal (Ctrl+`).
3. Run:
   ```
   npm install
   npm run dev
   ```
4. Visit http://localhost:3000

## Make it yours
Edit `data/site.js` (set your real email, GitHub and LinkedIn so recruiters can reach you): name, tagline, about text, skills, links and projects.
Colours and fonts live in `app/globals.css` (the `:root` block) and `app/layout.js`.

## Deploy
Push to GitHub and import the repo on vercel.com, or run `npm run build`.
